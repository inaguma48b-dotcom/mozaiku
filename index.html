MOSAIC.

ツール

効果

ブロックサイズ16 px
ブラシの太さ60 px

顔の自動検出

検出の厳しさ標準
いま選んでいる効果で、検出した顔を隠します。取りこぼしは手動で追加してください。

複数枚

「複製」は矩形ツールでの加工だけを、同じサイズの画像の同じ座標へ適用します。 スクリーンショットの決まった位置を隠す用途向けです。

読み込み

長辺の上限2000 px
スマホは大きな写真でメモリ不足になりやすいため、初期状態では携帯・タブレットのみ有効です。 復元データ入りの画像は座標がずれるので縮小しません。

可逆モザイク

SNS等にアップすると画像が再圧縮され、埋め込んだ復元データは消えます。 ファイルを直接受け渡す用途で使ってください。
忘れたパスワードは復旧できません。保存形式はPNG固定になります。

復元

画像を読み込むと状態を判定します。

操作方法

Ctrl+S … 保存
[ ] … ブラシ太さ
B / R … ブラシ / 矩形
P（長押し）… 原画を確認
← → … 前後の画像
Space+ドラッグ / 中ボタン … 移動
Ctrl+ホイール … 拡大縮小
2本指 … 移動・ピンチ拡大
